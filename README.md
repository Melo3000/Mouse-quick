# 鼠标连点器 (MouseQuick)

一个使用Python和PyQt5开发的功能强大的鼠标连点器工具。

## 功能特点

- 多种点击模式：左键单击、左键双击、右键单击
- 灵活的点击位置：固定坐标或跟随鼠标
- 可自定义点击间隔（毫秒级精度）
- 可设置点击次数或无限点击
- 支持热键快速启动/停止
- 配置方案保存/加载功能
- 两种点击方式：系统点击和直接点击(适用于网页)

## 安装方法

1. 确保已安装Python 3.6+
2. 安装依赖库：

```bash
pip install -r requirements.txt
```

## 使用方法

1. 运行主程序：

```bash
python mousequick.py
```

2. 在界面上设置点击规则、间隔和次数
3. 选择位置模式（固定坐标或跟随鼠标）
4. 选择适合的点击方法（普通应用用系统点击，网页用直接点击）
5. 点击"开始"按钮或使用热键（默认F8）启动
6. 再次点击按钮或按热键可停止连点

## 配置说明

- 点击类型：选择鼠标的点击方式
- 点击间隔：两次点击之间的等待时间（毫秒）
- 点击次数：设置为0表示无限点击
- 位置类型：
  - 固定坐标：始终在指定的屏幕坐标点击
  - 跟随鼠标：在当前鼠标位置点击
- 点击方法：
  - 系统点击：适用于大多数桌面应用
  - 直接点击：适用于网页和特殊应用
- 热键设置：可自定义启动/停止的快捷键

## 注意事项

- 本工具仅供学习和辅助操作使用
- 请勿用于违反服务条款的场景
- 在某些应用程序中可能无法正常工作
- 长时间使用请注意休息，避免鼠标和设备损坏
